Taming model behaviors with prompts.

You deployed and served a model in the previous modules. But right now, the model is completely generic. It knows nothing about mortgage lending, Fed Aura Capital's products, or lending regulations. When a borrower asks Lenora about mortgage rates, she gives textbook answers with disclaimers instead of actionable guidance. In this module, you will shape the model's behavior using system prompts and temperature controls in the GenAI Playground.

== Learning Objectives

By the end of this module, you will be able to:

* Access the GenAI Playground and interact with a deployed model
* Apply a domain-specific system prompt for mortgage lending
* Understand the effect of temperature on response consistency
* Select and use MaaS subscriptions within the Playground

== Module Summary

=== What You Accomplished

* Interacted with a generic model in the GenAI Playground and observed its limitations for mortgage lending
* Applied a domain-specific system prompt that transformed generic responses into actionable, persona-driven guidance
* Experimented with temperature settings and observed how lower values produce more consistent financial advice
* Configured MaaS subscriptions within the Playground interface

=== Key Takeaways

* A deployed model without a domain-specific prompt is not useful for production workloads - it gives generic advice with disclaimers
* System prompts are the simplest and most impactful way to shape model behavior for a specific domain
* Temperature controls are critical for financial applications where consistency and accuracy matter more than creativity
* MaaS subscriptions provide a managed way to access models with different tiers and access controls
