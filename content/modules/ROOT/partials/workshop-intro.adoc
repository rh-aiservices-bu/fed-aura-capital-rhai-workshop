== What you'll learn

In this workshop, you will build an end-to-end AI platform for mortgage lending using Red Hat AI. Through the lens of {company_name}, a fictitious mortgage lending company, you will:

=== icon:server[] Fast, Flexible, and Efficient Inferencing

* *Deploy and scale AI models* - Deploy an LLM on CPU with vLLM, then redeploy it with llm-d distributed inference across multiple replicas
* *Consume models as a managed service* - Reach a shared model through the MaaS gateway with a scoped API key, a rate-limited subscription tier, and per-key usage metering

=== icon:database[] Connecting Data to Models and Agents

* *Shape model behavior with prompts* - Use the GenAI Playground to engineer domain-specific personas and tune model responses for mortgage lending
* *Ground responses in private data with RAG* - Connect your models to internal policy documents so answers reflect your organization's rules, not generic knowledge

=== icon:cogs[] Accelerate Agentic AI Innovation

* *Connect agents to tools via MCP* - Register MCP servers so AI agents can call real tools: affordability calculators, risk assessments, compliance checks
* *Trace and evaluate agent decisions* - Use MLflow tracing to follow every tool call and LLM invocation, and run evaluations to measure quality
* *Train the model behind the tools (optional)* - Use AutoML to train the loan-approval classifier that the Risk MCP server calls, without writing model training code

=== icon:shield[] Securing AI from Sandbox to Production

* *Deploy guardrails at the inference boundary* - Configure NeMo Guardrails to filter harmful inputs and outputs before they reach the model or the user
* *Run adversarial testing with Garak* - Probe your models for prompt injection, jailbreak, and data leakage vulnerabilities before production deployment
* *Sandbox agents with OpenShell* - Securely onboard AI agents with deny-by-default policies, network isolation, and full OCSF audit logging

== Who this is for

This workshop is designed for:

* *Platform Engineers / MLOps* - who deploy and operate AI infrastructure
* *Data Scientists / AI Engineers* - who build and evaluate AI models and agents
* *Application Developers* - who integrate AI capabilities into business applications
