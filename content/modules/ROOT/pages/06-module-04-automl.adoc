Less gut feelings, more math.

Underwriters at Fed Aura Capital manually evaluate every loan application. Each review takes 5+ days, decisions vary depending on who reviews the file, and there is no structured audit trail beyond narrative notes. The board wants a predictive model to assist underwriting decisions, but the data science team lacks the ML engineering resources to build one from scratch. In this module, you will use AutoML in Red Hat OpenShift AI to train a binary classification model on historical loan data - no code required.

== Learning Objectives

By the end of this module, you will be able to:

* Explore a loan application training dataset and understand its features
* Create and configure an AutoML optimization run for binary classification
* Analyze AutoML results including model accuracy and leaderboard ranking
* Interpret feature importance to understand what drives loan decisions

== Module Summary

=== What You Accomplished

* Explored a real-world loan application dataset with features like credit score, DTI ratio, and risk score
* Created an AutoML optimization run that automatically trained and ranked multiple classification models
* Identified the best-performing model (ExtraTreesGini_BAG_L1_FULL) with 91.7% accuracy and 93.8% balanced accuracy
* Interpreted feature importance to understand which factors most strongly drive loan approval decisions

=== Key Takeaways

* AutoML removes the ML engineering barrier - you upload a CSV, select a prediction type, and get a ranked leaderboard of models
* The winning model uses decision_reason (29.17%) and risk_score (11.67%) as its strongest predictive features
* Balanced accuracy (0.938) is more meaningful than raw accuracy (0.917) for loan decisions because it accounts for class imbalance
* Feature importance provides the explainability that regulators and auditors require - no more "professional judgment" as the sole justification
